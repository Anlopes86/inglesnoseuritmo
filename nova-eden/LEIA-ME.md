# Nova Eden — pacote para GitHub Pages

Esta pasta ja esta compilada e pronta para publicacao. Nao e necessario instalar Node.js nem executar comandos para usa-la no GitHub Pages.

## Publicar dentro de um repositorio existente

1. Copie a pasta inteira `nova-eden` para a raiz do seu repositorio.
2. Envie as alteracoes para o GitHub.
3. Confirme que o GitHub Pages do repositorio esta publicado a partir da branch e pasta corretas.
4. A pagina ficara em um endereco semelhante a:

```text
https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/nova-eden/
```

Mantenha `index.html`, a pasta `assets`, o arquivo de audio e o icone juntos. Nao renomeie arquivos dentro de `assets`.

As votacoes e o progresso sao armazenados somente no navegador usado durante a aula. Eles nao sao compartilhados entre aparelhos.
